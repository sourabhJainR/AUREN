# Provider Pack

Load only when provider-specific execution or projection is required.

AUREN owns intent, routing, context selection, budgets, safety, verification and learning. Providers supply inference/native tools and must not redefine AUREN semantics.

Claude Code: `CLAUDE.md`, skills, hooks/MCP.
Codex: `AGENTS.md`, skills/MCP/plugins.
Gemini: `GEMINI.md`, hierarchical context, extensions/MCP/A2A.
ChatGPT: use an approved project/app, Codex-in-ChatGPT, MCP or API execution surface; ordinary chat is not assumed to be a local shell.

Preserve the same intent digest, boundaries, acceptance, protected behavior, capability plan and verification evidence. Unsupported capabilities are explicitly unavailable.
