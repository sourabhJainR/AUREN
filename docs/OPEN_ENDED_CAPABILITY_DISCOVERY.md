# Open-Ended Capability Discovery

This component is the bridge from measured external failures to capability
invention. It ranks evidenced capability gaps and creates falsifiable invention
proposals with explicit validation dimensions and rollback conditions.

It intentionally does not:
- execute invented skills;
- modify capability registries;
- promote or deploy capabilities;
- treat a benchmark score as proof of general intelligence.

The intended loop is:

external evidence -> transfer gap -> invention hypothesis -> independent
holdout curriculum -> experiment -> causal gate -> promotion or rollback.
