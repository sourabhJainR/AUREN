Download AUREN

Choose the current main build for the newest merged code, the latest stable release, or an older pinned version. Every published build includes a portable bundle and SHA-256 checksum.

Install latest stable

Linux / macOS

curl -fsSL https://raw.githubusercontent.com/sourabhJainR/AUREN/main/install.sh | bash

Windows PowerShell

irm https://raw.githubusercontent.com/sourabhJainR/AUREN/main/install.ps1 | iex

To pin an exact release, set AUREN_VERSION to its tag before running the installer. This also supports main snapshot tags.

Install a specific version

Copy the tag shown on a release card and set it before running the installer.

Linux / macOS:
AUREN_VERSION=TAG curl -fsSL https://raw.githubusercontent.com/sourabhJainR/AUREN/main/install.sh | bash

Windows PowerShell:
$env:AUREN_VERSION = "TAG"
irm https://raw.githubusercontent.com/sourabhJainR/AUREN/main/install.ps1 | iex

Release files are hosted by GitHub. Verify SHA256SUMS before installing if you need an integrity check. Stable version tags are immutable; main snapshots are separate prereleases.
