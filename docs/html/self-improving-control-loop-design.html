Self-Improving Control Loop

Design record for strengthening AUREN's existing context, decision, verification, graph, and learning spine without introducing competing authorities.

One authority per concernProvider-neutralDeterministicVerification-gated

Canonical flow

Context control

CodebaseIndex remains repository truth. CodebaseContext records snapshot identity and deterministic retrieval recipe, enabling safe reuse without a second index.

Operations

retrieve → rank → prune → compress → refresh → reuse. Every derived context can be tied back to the repository snapshot used to create it.

Planning artifact

TaskPlan remains the only planner and records execution intent such as parallel groups, checkpoints, and verification strategy with backwards-compatible defaults.

Graph semantics

StateGraph remains the only workflow engine. Explicit joins and cancellation enrich graph behavior while preserving deterministic merge and checkpoint semantics.

Typed decisions

The engineering-state ledger holds decision records. Probabilities are bounded metadata and require model identity; they never become verification truth.

Workflow evaluation

WorkflowEvaluation measures accuracy, Brier score, calibration error, abstention, latency, and token cost. Measurement cannot authorize release.

Compound learning

agency_adaptive_planning retains reusable lessons with evidence and recurrence outcomes. Learning stays advisory and cannot weaken gates.

Safety invariants

One owner per concern

No second repository graph, evidence store, durable memory authority, planner, capability catalog, or workflow engine.

Probabilities are not facts

A model can express belief. Verification records observed checks. The latter is authoritative for release decisions.

Learning cannot authorize

Learning can recommend a strategy or prevention rule; it cannot mutate policy, release gates, or canonical truth.

Parallel work must converge

Independent execution joins through deterministic graph semantics and downstream verification.

Portable stays neutral

Provider adapters can supply model execution without redefining capability semantics or workflow authority.

Implementation boundaries

Deliberate omission: no new decision database, no new planner, no new graph engine, no model-specific dependency, and no documentation runtime authority.
