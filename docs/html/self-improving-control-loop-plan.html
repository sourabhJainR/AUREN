Regression gates

API compatibility
Existing callers retain defaults and behavior unless a test demonstrates an actual contract defect.
Authority uniqueness
No new repository index, planner, graph engine, evidence store, memory authority, or capability catalog.
Probabilistic safety
Probability is metadata and measurement; it cannot become verification truth.
Learning safety
Lessons may recommend; they cannot authorize, bypass, or weaken release gates.
Offline documentation
HTML uses only inline assets and local navigation; no network/CDN dependency.
CI completeness
Do not stop at one green check. Inspect every available check and its job steps.

Implementation discipline

Step 1 — focused tests before change

Every runtime-facing addition gets a focused failing test before implementation, followed by the existing regression tests for that component.

Step 2 — architecture contract

Any new surface must have an explicit owner and cannot silently become a second source of truth.

Step 3 — integration sweep

Run the deterministic system suite and all CI-equivalent checks after each structural slice.

Step 4 — merge discipline

Merge only the exact reviewed head after the complete matrix is green.
