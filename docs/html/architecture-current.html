Operating rules

One owner per concern

No parallel repository index, graph, planner, evidence store, memory store, capability catalog, or workflow engine.

Probabilities are not facts

Model belief can inform policy, but only verification establishes observed truth.

Learning is advisory

Lessons can recommend strategy or prevention rules. They cannot authorize actions or weaken release gates.

Evidence is snapshot-bound

Evidence tied to stale repository truth must be refreshed before reuse.

Parallel work converges

Parallel execution remains a StateGraph strategy with deterministic merge and verification.

Portable remains provider-neutral

External providers, hosts, skills and reporting integrations remain outside canonical execution semantics.

Residual risks

Thread cancellation

Python threads cannot forcibly terminate arbitrary in-flight user code. Cooperative cancellation stops future scheduling; long-running work may require cooperative node behavior or process isolation.

Historical compatibility

Legacy surfaces remain only where compatibility requires them and are governed by the compatibility registry.

Calibration

Calibration is empirical. Reference probabilities are optional inputs to the evaluation harness.
