# Twelve-Phase Engineering Evolution

HWS now exposes one control plane for the requested twelve capabilities. Existing
specialized modules remain the owners of execution, verification, learning,
graduation, benchmarking and local inference.

## Phases

1. Canonical Engineering Evidence Envelope — immutable content-addressed lifecycle lineage.
2. End-to-end Evidence Graph — envelope, intent, repository, evidence and lifecycle stages become graph relationships.
3. Predictive WorldModel feedback loop — predictions are scored against observations and confidence is adjusted.
4. AER-aware context/evidence compaction — deterministic bounded key/value evidence representation.
5. Repository change impact prediction — dependency-aware impact analysis before execution/review.
6. Failure-pattern prediction before execution — persistent remediation history predicts risk and recommends controls.
7. Autonomous task decomposition using historical outcomes — unresolved historical findings become dependency-safe tasks.
8. Model/provider performance calibration — durable success, duration and quality measurements.
9. Cross-project learning validation — held-out transfer evidence with regression gating.
10. Engineering capability graduation — existing evidence-driven graduation gates are surfaced through the control plane.
11. Full autonomous engineering benchmark — benchmark success and transfer thresholds are explicit gates.
12. Production-grade local LLM execution path — embedded GGUF/llama.cpp is supported without an Ollama process.

## Persistent control loop

Review findings persist through PersistentRemediationBacklog and feed future
episodes. The evolution control plane consumes that history rather than keeping
another transient state store.

evidence -> graph -> prediction -> compact context -> impact/failure gates ->
historical decomposition -> provider calibration -> cross-project validation ->
graduation -> benchmark -> local execution

Every predictive component is advisory or gate-based. Existing safety,
verification, human approval, and release authorities remain authoritative.
